# Promptly Search

Quick desktop search tool with global hotkey support.

## Quick Start

1. **Double-click `promptly.bat`** to run(put this file in your startup for automatic start)
2. Press **Ctrl+Space**(Edit this in search_hotkey.py) from anywhere to search
3. Type your query and press **Enter**

## How It Works

- Runs in system tray (blue magnifying glass icon)
- Global hotkey: **Ctrl+Space**
- Opens Google search or direct URLs in your browser
- Right-click tray icon to quit

## Build Executable (Optional)


Double-click `build.bat` to create `Promptly.exe` for distribution.

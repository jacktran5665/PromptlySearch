# Search HotKey

Quick desktop search tool with global hotkey support.

## Quick Start

1. **Double-click `SearchHotKey.bat`** to run
2. Press **Ctrl+Space** from anywhere to search
3. Type your query and press **Enter**

## How It Works

- Runs in system tray (blue magnifying glass icon)
- Global hotkey: **Ctrl+Space**
- Opens Google search in your browser
- Right-click tray icon to quit

## Build Executable (Optional)

Double-click `build.bat` to create `SearchHotKey.exe` for distribution.
